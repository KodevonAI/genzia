string | null; notes: string | null } }`. Controlled state for `name`,

`{success:false}`: set the error-message state to
`t(\`errors.${result.error}\`)` when `result.error` is `nameRequired` or
`invalidIndustry` (map `invalidIndustry` to the same `errors.nameRequired`-

code), and specifically to `t("errors.nameRequired")`'s neighboring
`errors.saveFailed"` copy for `contactRequired`/`notFound`/`forbidden`/
`unknown` (D-02's own error copy in the UI-SPEC table conflates the
name-required and contact-required cases into one sentence — "El nombre es

string for both `nameRequired` and `contactRequired`, per the table's own
wording choice, rather than inventing a second string not in the UI-SPEC).

Fields, in this order, each `flex flex-col gap-1` with a `<label>` (Label

it minimal, no lock icon here, that stays a ficha-only detail). Submit

`t("editSubmit")`/`t("editSubmitting")` in edit mode, using `isPending`

| Client-form submission → Server Action | The form never sends agencyId/identity — only the plain field values, per plan 05-03's action signatures |
| Edit-route clientId → getClient | A caller navigating directly to another agency's/another member's client id must see the same "not found" outcome as a truly nonexistent id |
